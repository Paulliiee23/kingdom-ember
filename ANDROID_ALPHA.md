# Kingdom Ember Android Alpha

This branch packages the existing Vite/Three.js game in an Android WebView with Capacitor.

## Build using GitHub Actions (no local Android SDK needed)
1. Open the GitHub repository, select **Actions** > **Android Alpha APK**.
2. Choose **Run workflow**, selecting branch `feature/royal-ui-v095`.
3. Once the job succeeds, open the workflow run and download **Kingdom-Ember-Android-Alpha-debug** from Artifacts.
4. Unzip it, transfer `app-debug.apk` to your Android phone, and approve installation from your chosen file manager.
5. Use the same app ID and debug signing environment for upgrades; debug APKs built on different runners may have different signing keys and fail to update in place. For reliable upgrades, configure a **permanent release keystore** in repository secrets and create signed release APKs. Do not upload private signing keys to the repository.

## Local build
```sh
npm install
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

## Updating
The app checks the repository's **latest published GitHub Release** for a higher semantic version and offers a link. It does not silently install APKs. GitHub Actions artifacts are testing builds, not automatically published Releases. Publishing a properly signed release APK and a newer tag is a separate step.

## Castle GLB
The game expects `public/models/Royal_Castle_v095.glb`. Ensure that file is committed before building. If it is absent, the procedural castle fallback appears. The binary GLB is not automatically generated by this workflow.

## Save protection
Game progress currently lives in Android WebView localStorage. A new APK with the same application ID and signing key normally retains app data. **Uninstalling the app, clearing app data, or changing the application ID can delete the save.** Export/import backups and migration tests must be completed before treating upgrades as safe.

## Status
Android project is generated during the workflow. This is an alpha build pipeline, not a tested APK or a production OTA updater.
